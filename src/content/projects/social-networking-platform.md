## Overview

A full-stack PHP-based social networking platform built for triBBBal LLC.

## What I built

- Authentication, user profiles, post feeds, search and dynamic content, on a custom MVC-like architecture.
- Real-time community features — chat, forums, notifications and file uploads — using AJAX and Node.js WebSockets.
- MySQL database design and an administrative dashboard for user management, content monitoring and platform operations.

## Tools

PHP, MySQL, JavaScript, AJAX, Node.js WebSockets.

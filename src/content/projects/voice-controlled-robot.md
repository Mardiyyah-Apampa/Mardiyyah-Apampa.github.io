## Overview

A voice-controlled robot interface built so that people with physical disabilities can direct a robot using speech alone.

## What I built

- Integrated speech recognition and speaker verification with SpeechBrain, served through a Python Flask API.
- Connected recognised commands to robot navigation in Unity, using `NavMeshAgent` for pathfinding.
- Evaluated the system against functional suitability, usability and reliability criteria.

## Tools

Unity, C#, Python Flask, SpeechBrain, NavMeshAgent.
